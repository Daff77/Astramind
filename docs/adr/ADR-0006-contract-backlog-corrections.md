# ADR-0006: Pre-PB-008 Contract, Security, and Backlog Corrections (`SC-15`–`SC-20`)

- **Status:** Accepted (2026-11-24)
- **Context:** Independent QA identified six contract, security, and priority mismatches across `SYSTEM_ARCHITECTURE.md`, `DATA_SCHEMA.md`, `PRD.md`, and `MVP_TASKS.md` (`SC-15`–`SC-20`).
- **Decision:**
  1. **`SC-15` (`D-18`) Priority Alignment:** Promote search/filter/backlink scope of `PB-017` and create/open/backup/rebuild scope of `PB-018` to `P0` (matching `FR-001`/`FR-005` for `0.1`), keep Settings polish `P1`, and scope `PB-029` dependency on `PB-028` to "`PB-028` P1 portion done; P2 portion done or approved defer".
  2. **`SC-16` Core Use-Case Contracts (`SYSTEM_ARCHITECTURE.md` §4.1):** Add `create_vault`, `export_vault` (implemented in `PB-018`, verified in `PB-030`), `restore_trashed_note`, desktop-only grant CRUD (`create_grant`, `update_grant`, `revoke_grant`, `list_grants`), `set_note_verification`, `set_pinned`, composite `vault_id` on all note/proposal/revision commands, and `edited_body` + `verification` on `review_proposal`. Add note trash/delete UI to `PB-016`.
  3. **`SC-17` MCP Scope & Oracle Hardening (`SYSTEM_ARCHITECTURE.md` §8):** `get_project_context` uses vault-relative folder path (no phantom folder ID). `propose_memory(create)` validates `new_rel_path` is inside `grant_scopes`, has `.md` extension, and excludes `.obsidian`/`.git`/app artifacts. Out-of-scope source/target `note_id`s return an error indistinguishable from `NOTE_NOT_FOUND`. `list_pending_changes` filters by active grant scope.
  4. **`SC-18` Backup/Restore Hardening (`SYSTEM_ARCHITECTURE.md` §7.3, `DATA_SCHEMA.md` §8):** Restore-alongside generates a new `vault_id` (recording old→new mapping) and merges a new `registry.sqlite` entry with all grants disabled. Reject backup destinations inside the vault, inside `%LOCALAPPDATA%\PersonalBrain`, or as an ancestor of the vault. Refuse `create_backup` while `prepared` or `recovery_required` journal rows exist.
  5. **`SC-19` AI Frontmatter Spoofing & `supersedes` (`DATA_SCHEMA.md` §3):** Reject (`INVALID_INPUT`) proposals whose `proposed_text` sets `personal_brain_id`, `personal_brain.verification`, or `verified_at`. Display frontmatter `supersedes` (user-declared) alongside `note_status.superseded_by` (user-confirmed) without auto-syncing.
  6. **`SC-20` (`D-19`) Preview Security & Attachment Lifecycle:** Block `file://`, UNC (`\\`), and drive-absolute links in Markdown preview. Serve local attachments only via a core-served scoped protocol validating vault-relative paths (no broad Tauri `assetProtocol`). MVP lists and opens attachments but defers attachment move/delete/trash post-MVP.
- **Impact:** Updates `SYSTEM_ARCHITECTURE.md` (§4.1, §7.3, §8, §10), `DATA_SCHEMA.md` (§3, §8), and `MVP_TASKS.md` (§3) prior to `PB-008` contract freeze.
- **Verification:** Enforced in `brain-core` unit/integration tests across Phases 3–6 and Phase 8 regression gate (`PB-029`).
